# WooCommerce plugin — for owners who already have a WordPress site

This is the other way to use Kartify: instead of a hosted store, our products sync into their
existing WordPress/WooCommerce site. Each site gets its own key and its own invoice.

## Getting a key
Left menu → **"WordPress plugin"** → **"Request new key for WordPress plugin"**.
Fill **"Shop URL"** (their site address) and pick a **"Plan"**, then **"Add shop"**.
It starts as pending approval; once we approve it, an invoice appears and the key is issued.
Each site card shows "renews {date} · expires {date}" and its status.

## Installing it
Left menu → **"Set up plugin"**:
1. **"Download plugin"** — downloads the plugin zip file.
2. In WordPress: **Plugins → Add New → Upload Plugin** → choose the file → **Install** → **Activate**.
3. Open the **Authntic Products** menu in the WordPress sidebar.
4. Copy the key for that site from this screen (**"Copy key"**) and paste it in, then save.
5. Set the margin tiers, then click **Start auto-sync**.

## Common questions
**"Products aa nahi rahe"** — Check the key is pasted for the right site, the plan is active, and
auto-sync has been started. If it still doesn't sync, hand it to the owner.
**"Ek se zyada site?"** — Yes. Each site gets its own key, plan and invoice.
**"Hosted store aur plugin dono?"** — Yes, they are separate and can run together.
**"Apne products ki price?"** — Set the margin tiers inside the plugin.
